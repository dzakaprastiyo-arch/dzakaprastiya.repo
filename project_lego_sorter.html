ARCHITECTURE

Distributed Hardware + AI Pipeline

The sorting machine deploys an overhead camera module to capture component frames in real time along an automated conveyor belt. An Orange Pi 4 single-board computer runs a fine-tuned YOLO model for rapid part detection and classification. Once a component class is identified, serial signals trigger Arduino microcontrollers to actuate precision servo gates, directing each part into its designated compartment.

  • Real-time object detection and classification via fine-tuned YOLO.
  • Automated continuous conveyor mechanical feed.
  • Multi-channel servo routing to sorted bin bays.
  • Edge computing orchestration bridging vision models with physical actuators.
