ARCHITECTURE

Browser-Native AI Translation Pipeline

This browser extension executes directly within web-based manga readers. A YOLO vision model detects and isolates speech bubble boundaries on each page canvas before handing them to the text processing pipeline. Extracted Japanese dialogue lines are translated using contextual AI models that preserve narrative tone, humor, and character voices. The translated text is dynamically typeset into the bubbles with background inpainting, ensuring complete visual continuity.

  • Real-time speech bubble boundary localization via YOLO models.
  • Automated OCR text extraction tailored for vertical and horizontal typography.
  • Context-aware LLM translation preserving tone, idiom, and character voice.
  • In-place canvas inpainting and dynamic typographic re-rendering.
