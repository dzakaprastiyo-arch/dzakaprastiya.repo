SOURCE NOTE

Detail teknis tidak dibuat-buat.

Chrome extension ini digunakan untuk membantu proses penerjemahan manga secara langsung pada halaman browser. Sistem menggunakan YOLO untuk mendeteksi area speech bubble, sehingga lokasi teks pada panel manga dapat dikenali terlebih dahulu sebelum diproses oleh pipeline translation. Setelah bubble terdeteksi, area teks menjadi input untuk proses AI translation. Hasil terjemahan kemudian digunakan untuk menggantikan atau menampilkan teks dalam bahasa target sambil mempertahankan struktur visual halaman manga.
